## 二、项目简介

近年来我国持续推进"建设海洋强国"战略，沿海、沿河港口资源开发持续加快；同时风电场、渔业养殖场数量与面积不断增加，导致**重点水域的数量和范围持续增长**，给水域内船舶导助航服务带来更大压力。

随着沿海航运规模扩大，**船舶轨迹大数据爆发式增长**，但现有分析手段存在：交通流要素提取不全面、评估体系缺乏量化标准、难以高效处理海量时空数据，导致通航风险研判滞后、航路规划科学性不足。

本项目聚焦沿海水域船舶轨迹大数据，目标是：

1. 构建**智能化可视分析系统**，破解数据价值挖掘瓶颈，提升交通流态势感知的精准性与时效性；
2. 针对"数据多、洞察少"的核心问题，集成 **AIS 数据解析、时空特征挖掘、动态可视化**技术，精准提取船舶流量、密度、速度分布及典型航行模式，构建**量化评估体系**。

## 三、研究意义

1. **保障水上交通安全的关键支撑。** 海事监管重点水域指碍航物众多、航道弯曲狭窄、航路交织、船舶密集的水域，船舶操纵频繁、碰撞风险高；港口航道、施工水域、风电场与渔业养殖邻近水域是主要监管对象。
2. **应对海洋发展战略挑战的必要需求。** 在"建设海洋强国"战略下，沿海沿河港口开发与海洋新业态（风电场、养殖场）扩张，使重点水域数量与范围持续增长，对导助航服务提出更高要求。
3. **提升船舶交通流监管服务精细化与智能化水平的驱动力。** 依托船舶轨迹大数据与智能感知技术深度融合，构建具备自主数据采集、多维分析与动态建模能力的监管服务体系：部署轻量化 AIS 采集终端与智能分析模块，实现重点水域交通流状态实时感知；借助大数据挖掘解析航行规律、提取交通流特征参数，形成基于热力图可视化的船舶行为分析模型，推动监管从"经验驱动"向"数据驱动"转型。

## 六、研究内容

### 6.1 可视化技术（5 项）

1. **地图可视化**：基于国际标准（S-57/S-52）的电子航道图，将航道地理信息（水深、航标、建筑物）数字化，展示通航环境。
2. **图形可视化**：面向高维数据（速度、航向、吨位等），用**平行坐标轴折线**展现多变量关联与趋势。
3. **色彩编码**：利用色调/饱和度/亮度映射数据属性，增强传递效率。
4. **动态可视化**：船舶动静态信息实时动态展示，支持历史数据回放。
5. **交互技术**：支持数据筛选、区域绘制与多维度分析。

### 6.2 系统设计与实现

系统围绕**航道及通航环境、交通流基本要素、船舶动静态信息**三类可视化要素，从"系统功能 / 需求数据 / 关键技术"三方面做需求分析。技术选型（申报阶段）：

- 基础图表：Matplotlib / Plotly；地理信息融合：GeoPandas；
- 动态预测：LSTM / LightGBM（航迹与能耗）；
- 浏览器端平台：WebGL + Vue + ECharts，支持实时监控与交互分析。

### 6.3 交通流三要素定义

- **交通流量**：单位时间内通过某水域某地点的船舶总数；
- **交通流速度**：各船舶在特定水域内行驶速度的平均值；
- **船舶密度**：单位面积区域的船舶总量。
（原文附有平均交通量、平均行程速度、平均船舶密度的计算公式，此处从略。）

## 七、项目特色与创新点

### 7.1 项目特色

1. **多技术融合，提升分析能力**：融合 AIS、大数据分析、机器学习与可视化；利用 AIS 时空连续性与高精度特性建模，用机器学习提取典型航路、识别异常行为。
2. **软硬件结合的系统架构，实现全流程覆盖**：涵盖"数据采集—行为分析—效能评估"全链条；轻量化采集装置可灵活部署、实时接收 AIS；可视化软件完成交通流统计、行为分析与效能评估。

### 7.2 创新点

1. **轻量化采集装置设计**：体积小、电源多源（太阳能光伏 + 市电），突破传统设备对电源与空间的限制，适用于偏远或电力不便水域。
2. **可视化分析与建模方法创新**：
   - 交通流分析与热力图绘制：针对选定区域与横截面分析流量、区间速度、密度、船头间距，提取典型航路并绘制轨迹热力图；
   - 异常行为识别与建模：结合热力图与行为模型，在线监测重点船舶动态，实现异常行为精准识别。
3. **交通流分析领域的三大创新**：
   - **3.1** 构建多源数据融合的交通流动态分析体系，**首次将核密度估计（KDE）与平行坐标可视化结合**，实现流量/速度/航向角变化率的时空关联分析；
   - **3.2** 创建基于轨迹大数据的船舶行为建模方法，用 KDE 生成航行热力图并叠加典型航路提取，**声称异常检测准确率较传统经验分析提升 30%**（⚠️ 申报承诺口径，未实测）；
   - **3.3** 建立交通流驱动的量化评估范式，将密度分布、船舶领域模型等定量指标与用户评分结合，构建含**流量均衡度、速度离散度等 12 项交通特征参数**的评估体系。

## 九、预期成果（**申报书承诺口径**）

> 以下为申报时的承诺目标，**非实际达成值**；实际交付见 `plans/项目收口说明.md` 与 `doc/申报书承诺-系统实现对照表.md`。

1. **系统原型**：基于 AIS 数据的船舶交通流可视化分析系统原型
   - 功能：船舶实时检测与轨迹跟踪；多源数据融合（AIS/雷达/视频）解决遮挡下的连续跟踪；集成 AIS、电子海图（S-57）与环境数据，生成密度热力图与典型航路模型。

4. **社会应用**：声称降低重点水域碰撞事故率 ≥30%、提升港口通行效率 ≥15%；面向渔业管理、海上搜救、智慧航运示范应用。
