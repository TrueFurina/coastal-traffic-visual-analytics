## 新踩的坑（本项目实锤，重要）

- **变异验证脚本崩溃会污染实现**：用一次性 heredoc 跑变异，脚本中途异常退出 → 恢复语句没执行 → `metrics.py` 的熵被永久改成丢负号的版本，而后续全量测试仍"通过"（因为断言只查范围不查符号，恰好没触发）。**教训：变异脚本必须写成正式文件 + try/finally**，别用一次性 heredoc。
- **`np.float64` 是 Python `float` 的子类，`json.dumps` 能直接序列化** —— 所以「用 json.dumps 检查 np 泄漏」是**空测试**。要抓泄漏必须显式断言 `not isinstance(v, np.generic)`。
- **伪相关的假测试**：KDE「大带宽应削峰」测试原先不固定 `bin_size`，导致 bin 面积归一化效应掩盖了核退化（σ 常量化后测试仍绿）。改为**固定 bin_size 让带宽成为唯一变量**才真正有效。教训：断言"参数 A 影响结果 B"时，必须锁死其它会同时变化的中介变量。
- **uvicorn `--reload` 在本机不重扫**：改完路由后加端点返回 404，服务仍跑旧代码；必须 TaskStop 后重启。且 `--reload` 会残留子进程占住端口（`[winerror 10048]`），需用 PowerShell `Get-NetTCPConnection -LocalPort 8000` + `Stop-Process` 清。
- **Edit 替换别把锚点截断**：old_string 只写到 `> ` 而遗漏 `0)`，新串补上后末尾残留 ` 0)` 导致 SyntaxError。替换边界要含完整语句。
- **curl `-o /dev/null -w` 后接另一个 curl 管道给 python 会 exit 23**（write error），改成先 `-o` 落文件再单独解析。

### 本轮抓到的三个真 bug（都是测试逼出来的，不是读代码看出来的）

1. **`domain.py` 的 `along_nm/cross_nm` 泄漏 numpy 标量**：`round(d0 * np.cos(...), 4)` → np.cos 返回 np.float64，round 后仍是 np.float64。必须 `float(...)` 包住。原生类型护栏测试捕获（M10）。

3. **两套抽样语法并存**：`kde.py` 用 `USING SAMPLE N ROWS`，`multivariate.py` 用 `USING SAMPLE N ROWS (reservoir, seed)` —— 已统一为 `reservoir(N ROWS) REPEATABLE (seed)`（该语法实测可复现；`N ROWS REPEATABLE (42)`、`reservoir(42) N ROWS` 两种写法 DuckDB 都解析失败）。

### 关键数据事实（决定指标能否引用，比代码更重要）
本数据集 `course` 由相邻点位置反算，位置带 `rng.normal(0, 0.0008)`（~89m）独立噪声；船每 44s 仅前进 ~270m，
逐点差分角度误差可达 ~18°。实测平均 |ROT|：**逐点 79.9 → 5min 7.4 → 15min 3.50 → 30min 1.91 °/min**
（单调衰减 = 噪声主导特征）。故 **默认 15min 窗口口径**，逐点值仅作对照（diagnostics 给出放大倍数 ~23x）。
且 |ROT| 分布**单调递减无双峰** → 无天然"直航/机动"分界，3.0 °/min 是约定值，机动率只可相对比较。
→ 结论：该指标可用于水域/船型/时段的**相对比较**，不可把绝对值当真实转向率写进论文。

### 两个真 bug
1. **窗口口径被 `_MAX_GAP_S=600` 误杀**：15min 窗口跨度天然可达 900s > 600s，样本 126 vs 应有 2246（98% 丢失）。
   修：上界取 `max(max_gap_s, window_sec)`，下界要求窗口覆盖 ≥50%。
2. **`USING SAMPLE reservoir(N) REPEATABLE(seed)` 在 GROUP BY 之后不可复现**（连续 4 次首行 mmsi 各不相同）。
   根因：CTE 经 GROUP BY 后行序不确定，而 reservoir 抽样依赖输入行序。
   修：改 `ORDER BY hash(mmsi, hour, longitude, latitude, seed) LIMIT n` —— hash 是行内容纯函数、与行序无关。
   ⚠️ 这条是**通用教训**：任何"抽样前经过 GROUP BY/WINDOW 的 CTE"都不能用 USING SAMPLE 求可复现。
   本次 multivariate 也是被自己改成窗口 CTE 后才引入这个回归（原来直接扫 parquet 时可复现）。
